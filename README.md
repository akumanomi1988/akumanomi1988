## A bit about my work

Most of my professional background is in **C#, VB.NET, .NET and SQL Server**, especially desktop software and business applications. Outside of that, I spend a lot of time with **React, TypeScript and Python**, building my own apps, tools and games.

I enjoy working across the whole project: the database, the backend, the UI and whatever is needed to make it usable. I particularly like combining **WinForms + WebView2 + React** when a Windows app benefits from a modern interface.

The short version? **I like building software, not just writing individual features.**

## What keeps me interested

I tend to come back to the same kind of challenges: **large desktop applications, complicated data models, connecting old and new technology, and automating repetitive work**. I also spend plenty of time making games and experimenting with things I haven't built before.

I prefer software that's straightforward to understand and extend. If something can be solved cleanly without adding three new services, that's usually the direction I'll take.
